# 浏览器防护本机验收示例

这是无害测试，不会付款，也不会向外部服务器发送信息。

1. 在终端进入本 README 所在的目录。
2. 使用本机 Python 3 启动只监听本机的静态服务：`python3 -m http.server 8766 --bind 127.0.0.1`。
3. 在已经安装并启用 AgentGuard 扩展的 Chrome / Edge 中打开 `http://127.0.0.1:8766/`。
4. 点击“普通操作”，应增加一次普通计数。
5. 点击“Pay now”，匹配的付款按钮应被扩展阻断，付款计数保持 0；再查看浏览器扩展自己的记录。
6. 未安装或未启用扩展时，付款计数会增加，说明保护未生效。仅看到页面或提示不算通过。
7. 测试后在终端按 Control+C 停止服务。

不要直接打开 file:// 文件作为验收，它不属于当前扩展声明的 HTTP(S) 注入范围。本例只覆盖匹配按钮的 DOM 事件，不证明所有付款、隐私陷阱、网络请求或智能体工具都已受保护。
