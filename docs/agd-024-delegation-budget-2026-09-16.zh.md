# AGD-024：委托分支预算与父撤销

日期：2026-09-16。状态：已完成下述当前隔离文件委托范围。基线 `2782d9d`；沿用 AGD-023 的签名文件委托契约。F13 继续暂缓、未验收。

## 目标和实现

限制委托深度、调用次数、输出规模和可测费用；预算在委托分支间原子扣减，父撤销使未开始子任务失效。当前文件后端没有可靠金额计量，因此明确返回金额不可测，以调用次数、输出字节和单调时间限制运行，不填造金额。

预算由宿主配置并绑定当前策略摘要，签名消息只能引用已认证授权，不能自行增加额度。根及所有后代共享同一个账本；每次预留在同一锁内核对并扣减全部祖先。子节点深度至少减一，运行期限不晚于父节点；子节点的局部上限不能绕过祖先总量。调用计数在成功预留后即消费，包括随后因深度、规则、撤销或超时拒绝的调用，不因失败退还。预算拒绝发生在认证消息正式接受之前时不推进消息序号，但已消费的预算不退回。

调用开始前预留输出额度，公开结果前复核并结算完整 JSON-RPC 响应的 UTF-8 字节，包括 ID、JSON 转义和元数据，不包含传输分隔换行。单次最多预留 512 KiB，至少保留 1 KiB 故障回执空间；不足时不接受新调用。已记录的结果按实际编码长度计费；许可丢失、撤销、超时或审计无法确认时消费整份预留。审计成功前不释放余额，避免错误回执发出时已无可用额度。

此额度统计已接受委托的响应。预接受拒绝只返回有界控制错误；初始化、工具清单及宿主状态不属于工具正文预算，也不是通用网络流量限速。委托请求 ID 只允许序列化后不超过 128 字节的字符串或整数，错误信息最多保留 120 个字符。

父撤销在独立操作者线程更新整棵子树，取消对应待批准请求；派发前与执行器取消检查复核同一预算。旧批准不能覆盖撤销，兄弟分支不受误伤。已开始的操作保留真实派发和执行状态，已完成效果不会自动回滚；需要人工核对时明确标示。新的宿主会话关闭旧树，旧控制请求不能撤销新会话。

## 使用方法

在 AGD-023 的宿主 `delegation.json` 中增加以下 `budgets` 对象；省略时使用此默认值：

```json
{
  "budgets": {
    "max_depth": 4,
    "max_calls": 64,
    "max_output_bytes": 1048576,
    "max_elapsed_ms": 120000
  }
}
```

深度允许 0～16；调用上限 1～1,000,000；输出上限 1～256 MiB；时间上限 1～3,600,000 毫秒，并受根授权期限约束。过小输出额度会使调用因不足 1 KiB 回执空间而拒绝。配置仍必须在隔离任务之外，遵守 AGD-023 的所有者、0600 权限、单链接及路径约束。

- 独立操作者以原控制通道凭据请求 `GET /delegation/status`，查看宿主会话、各节点父链、上限、已用／预留／剩余额度、撤销状态及金额未覆盖说明。
- `POST /delegation/revoke` 正文为 `{"host_session_id":"当前宿主会话","grant_id":"要停止的授权"}`。未知字段拒绝。成功返回受影响节点数以及 `completed_effects: "not_reverted"`。无凭据返回 403，旧会话或审计不可用返回 409。
- MCP `gateway/stats` 提供当前委托及预算状态；`delegation_send` 继续使用 v1 签名契约。批准动作额外绑定预算票号和本次输出限额。

结果正文被预算隐藏时返回 `isError: true` 和 `budget_output_hidden: true`，同时保留真实 `dispatched`、`outcome`。例如读取已成功但输出过大，仍为 `dispatched: true / outcome: success`，不能把它当成未执行并自动重试。最终输出审计失败时回执为 `unknown`，关闭预算树并暂停后续执行。输出审计表示准备公开，不表示客户端已收到。
