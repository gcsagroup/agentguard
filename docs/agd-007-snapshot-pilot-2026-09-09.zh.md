# AGD-007：隔离工作区工具试点

日期：2026-09-09。适用范围：当前 Mac 上的本地 Docker Linux VM，经 `agentguard-mcp` 调用的小型 Python／Node／文件任务。现已接入桌面连接文件导入与独立差异回写；完整桌面任务启动和 M1 联合验收尚未完成。新流程及最终验证见[回写与会话续作](agd-m1-workspace-control-2026-09-09.zh.md)。

## 已能使用的能力

操作者从计划选定授权目录后，网关复制到独立私有目录，把副本挂入固定镜像。`run_shell`、`read_file`、`search_file`、`write_file`、`delete_file` 都在容器里执行。写入和删除只改变副本；`gateway/stats` 返回真实快照位置、挂载范围、镜像摘要和审计健康状态。

副本创建不跟随用户符号链接，普通文件按字节复制，原有 hardlink 不再共享宿主 inode。macOS 的已知 `/private/var`、`/var` 与 Data 卷别名映射到同一份副本，脚本中的实际路径可以继续使用。授权后把宿主根目录换为用户链接，不能让容器获得新的宿主目录。

结构化读、搜、写、删逐级打开父目录，不跟随快照内的父目录链接，避免逻辑目标被重定向到另一个文件。正常创建嵌套目录仍支持；需要依赖目录链接的项目应使用明确授权的脚本路径，并理解脚本批准不逐项列出其内部副作用。

每次执行使用新容器：非 root 用户、只读系统目录、能力清空、禁止提权、默认断网，最多 64 个进程、256 MiB 内存、1 CPU、30 秒及 64 KiB 正文输出。宿主取消会删除该容器；容器内部另有期限，网关进程遭到强制终止也不会让任务无限存活。容器清理结果无法核实后，当前执行器禁止继续启动新动作。

批准接口使用协议 2。完整动作包括最终参数和写入正文，操作者回传批准 ID、动作 SHA-256 与独立随机值，旧批准不能重放。隔离模式的批准令牌写入宿主控制连接文件，既不进入 MCP 标准输出，也不写到客户端日志。

## 运行一次已有验收

在仓库根目录运行：

```bash
./scripts/bootstrap-rust.sh -- cargo build --locked -p guard-gateway --bin agentguard-mcp
node scripts/acceptance/agd-isolation-gateway.mjs
```

脚本使用本机已验证的 Node／Python 运行时，只创建自己的临时目录、测试文件和容器，并由测试控制面批准这些合成动作。输出新的 `eval/out/AGD-002/<运行编号>-gateway/report.json`；它验证检查点，不等于 50 个完整用户任务。镜像不存在时明确失败，不下载替代镜像或回退原生执行。

本机运行时为 `sha256:7de5789da80158e418d22bf911ea3829aa1abdeb2338dd556dc99b13c89d8490`。来源、Node 官方包摘要、构建脚本和平台边界见 [后端验证记录](agd-002-isolation-backend-2026-09-09.zh.md)。这是当前开发环境的固定候选，不能直接当成跨平台发布镜像。

## 接入自己的小型工作区

准备一个只包含本次授权内容的目录，创建宿主持有的计划文件，例如：

```json
{
  "plans": [{
    "task_profile": "isolated-code",
    "allow": ["run_shell"],
    "scope": {
      "paths": {
        "read": ["/绝对路径/项目"],
        "write": ["/绝对路径/项目"]
      }
    }
  }]
}
```

将计划、审计库、控制连接文件放在授权目录之外。控制文件父目录必须存在，文件名必须是新的，不能通过用户符号链接间接选择父目录。调用方式如下，实际客户端通过 stdio 发送 MCP 请求：

```text
target/debug/agentguard-mcp
  --rules crates/guard-schema/rules/p0_rules.yaml
  --shell-policy crates/guard-shell/policies/default.yaml
  --plans /宿主持有的目录/plans.json
  --task isolated-code
  --isolation-image sha256:7de5789da80158e418d22bf911ea3829aa1abdeb2338dd556dc99b13c89d8490
  --audit-db /宿主持有的目录/audit.db
  --control-file /宿主持有的目录/本次新连接.json
  --confirm-port 0
```

上面是参数清单；客户端配置时应按参数数组填写。不要把批准连接文件交给 Agent。其 JSON 含本次控制 URL、端口、协议版本、实例 ID 和令牌；令牌只用于操作者控制面。正常退出清理本实例文件；强制终止可能保留旧文件，旧令牌随进程失效，重启需要新文件名，不能覆盖旧文件。桌面现在可以用“选择连接文件”载入此文件，令牌留在 Rust 控制面，不进入网页界面。

执行后可以查看 `gateway/stats.execution_backend.workspace_mounts` 中的副本目录，或在桌面选择工作区预览差异。**原工作区没有自动回写。** 支持的普通文件经完整差异复核后逐项应用；冲突不会覆盖用户编辑，部分或未知结果会停止后续动作并保留恢复原件。具体上限、支持范围及操作步骤见[回写与会话续作](agd-m1-workspace-control-2026-09-09.zh.md)，不能把副本整棵覆盖回项目。

## 目前的限制

- 网关控制入口与容器内工具已实测；客户端原生工具、其它 MCP 服务及宿主同用户进程仍可能旁路，不能将整个 Agent 标为隔离会话。
- 只支持互不重叠或相同读写权限的目录授权。不同读写权限的嵌套目录、单文件授权、Socket／设备／管道、凭据目录、超过 20,000 个对象或 512 MiB 的目录会拒绝启用。不会静默跳过项目文件来凑出成功结果。
- 容器提供自己的系统文件和临时目录；“越界拒绝”指未授权的宿主文件，不能解读成程序只能读取项目内的每一个字节。工作区中已经存在的内容也不能仅凭快照复制证明来源可信。
- 默认不能联网；联网安装依赖、远程 API、模型数据出口和凭据代理尚未完成。原生 macOS 构建、GUI、Keychain 与系统自动化不属于 Linux 工具试点。
- 审计当前保存脱敏摘要、判决与工具结果。工具退出成功不等于业务目标独立验收；结果未知不自动重试。等待批准的旧进程终止后，批准失效，不会在新会话自动恢复。
