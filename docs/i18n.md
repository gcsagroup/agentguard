# Internationalization

AgentGuard clients support:

- English (`en`)
- Simplified Chinese (`zh-Hans` / `zh_CN`)
- Traditional Chinese (`zh-Hant` / `zh_TW`)

The default is **System**. Users can override the language inside each client.

## Client implementations

- macOS: `apps/desktop-macos/src/i18n.js`; selection is stored in
  `localStorage["agentguard.locale"]`.
- Windows: `apps/desktop-windows/src/i18n.js`; uses the same storage key and
  locale resolution rules.
- Chromium: standard Manifest V3 `_locales/` dictionaries localize the
  extension manifest. The popup also supports an override stored in
  `chrome.storage.local.localeOverride`.
- Android: Android resource qualifiers (`values`, `values-zh-rCN`,
  `values-zh-rTW`) provide translations. `LocaleController` stores the
  application override in SharedPreferences; the language button cycles
  System → English → 简体中文 → 繁體中文.

## Locale resolution

- `zh-CN`, `zh-SG`, or another generic `zh` locale → Simplified Chinese.
- `zh-TW`, `zh-HK`, `zh-MO`, or an explicit Hant locale → Traditional Chinese.
- Other locales → English.

Security detection patterns and machine-readable rule IDs are deliberately not
translated. This prevents localization from changing matching behavior.

## Verification

```bash
node --check apps/desktop-macos/src/i18n.js
node --check apps/desktop-windows/src/i18n.js
node --check apps/extension-chromium/popup.js
cargo check --manifest-path apps/desktop-macos/src-tauri/Cargo.toml
cargo check --manifest-path apps/desktop-windows/src-tauri/Cargo.toml
cd apps/android-companion && ./gradlew :app:assembleDebug
```
