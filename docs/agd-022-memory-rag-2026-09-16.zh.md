# AGD-022：网关记忆读写与文档型 RAG

日期：2026-09-16。状态：AGD-022 原任务范围已完成；适用当前宿主与已验证后端。前置为已提交的 AGD-021；F13 继续暂缓，不改变完整原 M1 和发布的未通过状态。

## 本批目标与完成标准

在真实 `agentguard-mcp` 网关上提供记忆读写及一种 UTF-8 文本文档检索。通过独立宿主控制通道批准保存，重启后读取仍有出处与版本；在新会话中确认过期或撤销内容不再进入检索结果和模型任务。直接工具调用、模拟批准、真实模型消费和原生人工批准分别记录，不互相替代。

## 接口与边界

- 复用签名 `MemoryStore`，不建立第二份可残留旧内容的检索缓存。配置由宿主绑定一个作用域、读写能力及独立数据库／见证／签名密钥／公钥路径；这些文件须在任务授权目录之外。客户端不能提供作用域、标签、来源或批准记录来扩大授权。
- `memory_write` 保存有界普通记忆；`memory_read` 读取一个当前有效版本；`memory_revoke` 追加撤销版本。变更必须绑定预期版本，正文、来源、标签、目标和期限进入单次批准。
- `rag_import` 通过已有工作区读取流程获得 `.txt`／`.md` UTF-8 快照，再批准保存完整文档及实际路径、摘要。文件字节和守卫附注分开，不能把注释或模型自报正文冒充文件内容。
- `rag_search` 对当前有效文档进行有界关键词检索，返回原文片段、行号、路径、正文摘要、记忆版本／摘要、来源、标签和期限。无需网络嵌入服务；这是首个文档型检索接入，不宣称通用语义检索或 Office／PDF 支持。
- 读回的记忆与检索片段进入现有来源采集器，完整历史来源仍保留。它们是数据，没有指令权限；同一已签名来源不能被替换或降低限制。
- 记忆变化走独立批准与撤权互斥；数据库或见证结果未确认时停止会话，不自动重试。读取和返回前均核对会话、有效期、工具登记、规则版本及审计状态。
- 仅宿主显式启用的本存储被覆盖；第三方不可访问的内部记忆始终显示“未覆盖”。原生治理入口归 AGD-026，不能以命令行接线提前记为原生完成。

## 宿主配置与使用

仅 macOS／Linux 的宿主配置可启用该接口。`--memory-config` 必须与已有隔离镜像、持久审计和独立宿主控制文件同时使用；数据库、见证、签名密钥、公钥及可选加密密钥必须位于任务授权目录外，父目录为当前用户的私有目录，配置和密钥为单链接的 `0600` 普通文件。与审计或控制文件重名、位于工作区、损坏或缺失的存储均拒绝启动，不隐式重建。

配置结构示例（路径替换为当前宿主的固定私有目录）：

```json
{
  "schema_version": 1,
  "scope_id": "project-memory",
  "database": "/absolute/private-host/memory.db",
  "witness": "/absolute/private-host/memory-head.json",
  "signing_key": "/absolute/private-host/memory-secret.hex",
  "public_key": "/absolute/private-host/memory-public.hex",
  "allow_read": true,
  "allow_write": true,
  "encryption": {
    "mode": "sqlcipher",
    "key_file": "/absolute/private-host/memory-cipher.txt"
  }
}
```

签名密钥／公钥复用既有 `guard-cli audit-keygen` 格式，公钥也须收紧为 `0600`。加密构建启用 `guard-gateway/memory-sqlcipher`；未包含 SQLCipher 时明确拒绝，错误口令不能读库。首次启动另加 `--initialize-memory`；之后只使用 `--memory-config`，已有存储不能再次初始化。`plaintext_test` 是明确标记的合成测试模式，发布构建拒绝该模式。本轮跨进程 CLI 验收使用该测试模式，真实密文和错误口令由启用 SQLCipher 的网关测试单独验证。

工具请求继续绑定 `agentguard_session_id`。写入、导入和撤销需要独立控制通道批准，批准页面包含完整最终记忆草稿；客户端不能提供 `trusted`、来源、标签或批准对象。读取依据任务计划中的实际 `data_keys` 核对；检索先过滤授权条目，再应用结果数量上限，判决时再次核对所有返回条目。没有授权资料时返回空结果，不公开其它条目的正文或名字。一次检索只计一次 `recall_memory` 预算，写入计 `persist_memory`；计划的严格程度仍遵守既有契约。
