# 14 天 Beta 运行手册

## 开始条件

- RC 技术门禁已通过，六端候选的 commit、版本、build ID 和 SHA-256 已冻结。
- Beta 群体规模、同意/退出方式、数据最小化、指标口径、停止阈值和值班人已记录。
- 回滚包、关闭开关、[事故手册](incident-response.md) 和 [支持手册](support-runbook.md) 已演练。

## 计时和重置

Beta 开始时记录唯一 RFC3339 UTC 时间。只有同一候选系列连续观察满 `14×24` 小时才算完成。改变安全/隐私/核心判决的新 commit、无法证明兼容的重新打包、Sev-0/Sev-1 事故或指标中断会重置时钟；只改文档的例外必须有 Release+QA 书面理由。

## 每日必查

- 分渠道活跃数、升级/安装/首启成功率、崩溃/无响应、守护进程可用性。
- 拦截漏报/误报、确认队列卡死、观测权限丢失、审计完整性与数据泄露信号。
- 支持工单数、重复问题、影响人数、响应/解决时间，以及未关闭 Sev-0/Sev-1/Sev-2。
- 一切调查截图/日志先去除 PII 和凭据，原始数据按隐私保留期放在受控系统。

## 停止与通过

任一 Sev-0/Sev-1、未受控扩大的安全/隐私事件、无法回滚或关键遥测缺失都立即停止 Beta 并执行事故流程。通过必须由 Release 与 QA 复核完整日志，确认无未关闭 Sev-0/Sev-1、所有预定阈值均达标，并生成 BT1–BT4 四份唯一证据。门禁只机检 14 天时间与材料形状，不替代指标真实性和人工审查。
