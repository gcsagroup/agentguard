# 上線支援手冊

六端各需公開支援入口、時區／值班、負責人與升級鏈，且商店、應用內與隱私頁連結一致。準備已審查的簽署／安裝、權限、觀測、誤報／漏報、確認佇列、審計恢復及安全上報答覆。只收集必要版本、渠道、錯誤碼與脫敏日誌；不要求密碼、簽署密鑰、令牌、完整畫面或無關檔案。

工單記錄接收時間、平台／版本／渠道、現象、影響與經同意的診斷材料。先分類使用問題、限制、缺陷、安全／隱私事件或渠道／簽署故障。可能影響保護語義、多用戶、更新鏈或個資者立即轉[事故回應](incident-response.zh-TW.md)，不可自行降級。回覆只陳述已驗證事實、可恢復步驟及真實更新時間。

按渠道聚合工單量、首次回應／解決時間、重複問題、嚴重性與退出。Beta 及每一擴量階段前，Operations 將支援摘要納入健康決策；支援文件修訂也需評審、版本化及變更日誌。
