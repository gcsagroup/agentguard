# 首个 GA 的跨浏览器范围

> 结论：首个 GA 只支持 Chrome 与 Edge，二者共用同一个 Chromium ZIP。Firefox 仅保留源码原型，不打包、不提交、不作为首个 GA 验收门；Safari 是独立产品线。GA 浏览器包禁用 Native Messaging。

## 首个 GA 支持范围

| 项目 | Chrome | Edge |
|---|---|---|
| 发布包 | `agentguard-extension.zip` | 与 Chrome 共用同一 ZIP |
| 页面扫描 | `document_start` 的 isolated content script；浏览器允许注入的各 HTTP(S) frame | 同 Chrome |
| 高风险 DOM 动作 | 执行前 block-only；不在网页内放行 | 同 Chrome |
| 静态付款 DNR | 默认启用；按声明的关键词、HTTP(S)、非 GET/HEAD 和资源类型硬阻断 | 同 Chrome |
| Native Messaging | GA manifest 不含 `nativeMessaging` | GA manifest 不含 `nativeMessaging` |
| 验收 | Chrome 商店候选独立留证 | Edge 商店候选独立留证 |

Chrome manifest 的 `minimum_chrome_version` 与所用 DNR 能力一致。Edge 使用相同的 `chrome.*` API、manifest、内容脚本和规则。共享源码与 ZIP 不代替两家浏览器各自的安装、升级、权限提示和运行时验收。

## 共同安全边界

- 浏览器允许注入的 HTTP(S) frame 内，匹配的付款／转账点击与隐私陷阱个人信息提交会同步阻断，不重放原动作。
- 页面内提示只是可被网页删除、遮挡或仿冒的信息层，不是授权 UI。
- 用户若确需继续，只能从 `chrome://extensions` 或 `edge://extensions` 停用或移除保护，再自行重做操作；网页内无“允许一次”或临时例外。
- 静态 DNR 是独立 block-only 网络层：仅覆盖规则列出的付款路径关键词、HTTP(S)、非 GET/HEAD，以及 `xmlhttprequest`、`ping`、`main_frame`、`sub_frame`。
- 静态 DNR 还明确覆盖规则列出的逐字节百分号编码路径变体，以及查询键 `op`、`action`、`operation` 等于付款标记的形状；它不检查 body，也不声明覆盖 body-only、自定义别名、未列编码/混淆形式、任意查询键或值、WebSocket/WebTransport 或其他资源类型。
- 页面 `postMessage`、旧 decision/scope 消息和普通页面 DOM 均不是信任根。

精确关键词、字符边界和负向范围见[浏览器执行前阻断](浏览器执行前阻断.md)。

## Firefox：源码原型，不是首个 GA 产品

仓库保留 `manifest.firefox.json` 与兼容性源码，目的是为后续研发保留起点，不代表发布支持：

- `package-store.sh --firefox` 必须拒绝执行，不得生成 Firefox 商店包；
- 首个 GA 的 release gate、验收清单和上线结论不得要求或引用 Firefox PASS；
- Chrome / Edge 的 E2E 不能当作 Firefox 运行时证据；
- Firefox 原型文件存在、版本一致或结构测试通过，都不能升级为“支持 Firefox”的声明。

Firefox 若进入后续版本，必须另行完成 manifest、DNR 行为、权限、商店打包与真实浏览器验收，届时再更新支持矩阵。

## Native Messaging：GA 禁用

GA manifest 明确不申请 `nativeMessaging`，Chrome / Edge ZIP 也不含 Native host。仓库可保留 host 源码、安装模板和实验性连接代码，但它们不是首个 GA 运行路径、商店能力或验收依据。首个 GA 不声明 Native 判决、动态主机阻断、host 通知或本机审计链。

## Safari：独立产品线

Safari Web Extension 通过独立 Xcode 应用壳、Extension target 和 Apple 签名流程交付，不使用此 Chromium ZIP，也不属于本文件定义的首个 GA 浏览器范围。

## 验证边界

`make check-extension-gate` 应验证 Chrome / Edge 包、block-only DOM 行为、静态 DNR、GA manifest 无 Native Messaging，以及 Firefox 打包被拒绝。自动化通过仍不是 Chrome / Edge 的商店候选真实浏览器 PASS；最终状态以各自非历史、与候选产物绑定的新证据为准。
