# AGD-027：首次启动的系统阶段与签名对照

日期：2026-09-16。源码基线：`9df7323f3f1821849224928132c7bec8dd57f0e7`。本批没有修改网关源码或原预算；复用[新数据库性能候选](agd-027-sqlite-performance-2026-09-16.zh.md)的准确 CLI 字节，增加进程外计时与系统诊断。

## 已经定位到的阶段

开启本机 `dyld` 手册明确支持的 `DYLD_PRINT_LOADERS`、`DYLD_PRINT_INITIALIZERS`，记录创建进程返回、首条加载日志、首条应用启动日志及 MCP 握手。计时点来自宿主收到日志的时刻，不是每个系统操作的精确开始／结束；诊断开销不计正式性能验收。

| 原始 CLI 对照 | 首条加载日志 | 首条应用日志 | 完整握手 |
| --- | ---: | ---: | ---: |
| 开发构建，新路径首次 | 573.375 ms | 579.174 ms | 619.951 ms |
| 同路径重复启动 | 2.355 ms | 8.540 ms | 37.917 ms |
| 同路径改为优化构建 | 2.401 ms | 8.434 ms | 37.104 ms |
| 优化构建重复启动 | 2.392 ms | 8.284 ms | 35.428 ms |

首次的主要等待发生在应用启动日志之前；后续业务初始化约 27～41 ms。系统日志中存在同一进程／路径的 Gatekeeper、XProtect 和允许执行记录。Apple 也说明首次启动、文件变化及 XProtect 签名更新会触发相应检查，见[Gatekeeper 说明](https://support.apple.com/guide/security/gatekeeper-and-runtime-protection-sec5599b66df/web)与[XProtect 说明](https://support.apple.com/guide/security/protecting-against-malware-sec469d47bd8/web)。这些证据支持继续检查系统启动阶段，**没有精确测出整个间隔都属于 XProtect**。

## 签名不是充分修复

另准备两个固定 CLI 副本，以临时签名、组织签名、组织重复、临时重复的预定顺序执行。组织签名使用现有证书 `7C33B517942161311A087CE893D2F1CE9B204B44`，核对叶证书 SHA-1 及严格签名校验；14 个实际存于文件的 Mach-O 节在签名前后逐字一致。

| 签名对照 | 首条加载日志 | 首条应用日志 | 完整握手 |
| --- | ---: | ---: | ---: |
| 临时签名首次 | 1,890.291 ms | 1,898.179 ms | 1,934.421 ms |
| 组织签名首次 | 648.219 ms | 659.431 ms | 698.601 ms |
| 组织签名重复 | 5.278 ms | 12.155 ms | 41.765 ms |
| 临时签名重复 | 3.929 ms | 10.188 ms | 38.714 ms |

两个首次进程都有 XProtect 检查记录，两种签名都未满足原 100 ms 启动预算。此四轮不足以量化签名带来的稳定收益。测量后的独立 `spctl --assess --type execute` 对两份 CLI 均返回 3／`rejected`；该结果只属于这两个独立副本，不是固定开发 App 的原生启动结果。现有证书类型是 Apple Distribution，本机没有 Developer ID Application 身份；正式签名、公证和发布仍需独立证据，不能承诺公证必然解决本项时限。

## 采样及核对

另一次新路径启动使用系统 `sample` 实际采集调用栈：可见程序入口前的 `_dyld_start`，之后才进入 `agentguard_mcp::main`；本轮握手约 744.533 ms。采样还引入了动态加载器的同步调试通知等待，故不能把采样总时长或样本数当成无诊断时的真实分项耗时。

九次运行均实际完成初始化、状态查询及一次 1 KiB 读取后正常退出。独立核对器重算各时间点，从九组真实数据库核对 **72 条无签名审计的哈希链**及九份返回摘要，并拒绝换候选、缺轮、倒置时间、伪造首条日志和子进程失败五类变异在三组记录中的 15 个反例。没有将这些无签名夹具称为固定 App 的签名审计。

固定 App 023 的 91 个文件与原清单保持。本批仅补充诊断，原四轮性能失败、F13 暂缓和发布 No-Go 继续保留；不会通过预热、去掉首次样本或改变系统安全策略取得通过。原始记录及可执行核对器位于 `.artifacts/m3-startup-phases-2026-09-16/`，公开摘要见[证据索引](evidence/m3-startup-phases-2026-09-16.json)。
