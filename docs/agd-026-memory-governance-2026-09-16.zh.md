## 可以使用的入口

在“主动防护”中导入本次宿主会话的连接文件，进入“记忆与委托治理”。只有宿主已经配置并授权的记忆和委托可用；界面不会替第三方客户端开放内部记忆，也不会自动增加工作区权限。

1. 点击“读取记忆列表”，查看正文、完整来源、标签、版本、有效期及批准依据；列表每页 16 条，历史每页 8 版。
2. 隔离、撤销和恢复先展示完整变更，核对后才提交。恢复须选择已存储的历史版本和未来有效期，生成新版本，保留已有来源及限制标签，不重新读取外部文件。
3. 点击“读取委托树”，按父分支关系查看预算与状态；“停止此分支及其下级”走独立控制通道，能取消仍在等待批准的请求。已完成外部操作不会撤回，界面明确提示必要时人工补偿。

操作者令牌和一次性批准随机值留在原生层。批准绑定连接实例、会话、策略、当前版本、完整草稿及摘要；过期、暂停、停止、断连、版本变化或消费后不能复用。提交后回执不明会清除批准并提示核对，不自动重试。不可信正文作为文字展示，不作为 HTML 或指令执行。

当前 App 自带的原有网关及浏览器接入资源逐字保留。此次新治理能力使用显式配置记忆／委托的独立 CLI，经连接文件接入；“本地模型任务”的内置启动表单尚未提供这两类配置，不能把本轮结果解释为该表单已自动启用记忆或多 Agent。
