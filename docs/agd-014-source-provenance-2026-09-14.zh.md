# AGD-014 来源标记首批实现

日期：2026-09-14。状态：**开发中，未记整项完成。** F13 已由用户明确暂缓，F14 Docker 虚拟链路已通过，本轮按这个例外接续 M2。

## 已实现

- 来源对象增加公开、内部、敏感、未知四种敏感度。旧缺省记录按未知处理，序列化保持契约 1 原字节；共享浏览器夹具与批准绑定继续回归。未知来源不得标成公开或其它已知级别。
- 宿主采集器根据实际内容字节计算 SHA-256，记录入口、解析器版本及本采集器已登记的父来源。派生内容继承更严格的限制；正文包含 `trusted: true` 或客户端修改返回副本，均不能清除已登记的父标签。未知父 ID（包括采集器重建后的旧引用）保留未知，不自动信任。
- 执行日志在原动作摘要之外保留来源敏感度、入口、内容摘要和来源关系摘要；任意来源 ID、解析器说明及未知原因均只保存摘要，正文不落盘。缺来源明确记为 `missing`，不是“安全”。日志重开后的未知回执沿用原来源约束。
- 敏感度参与新动作的批准绑定，改标签必须重新批准。所有标记都只表示来源约束，不授予目标权限、取消批准或放宽出口。
