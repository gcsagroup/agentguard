# AGD-032 前置准备：默认身份模板与部署自检

日期：2026-09-16。源码基线：`217e184604fc7f4eaec0fb6bed3390ba3c8bddb0`。结论：默认 Agent 身份模板不再携带公开测试公钥，历史错误配置仍被拒绝。**这是发布准备修正，不是 AGD-032 或发布验收通过。**

## 改动与边界

从干净的基线工作树构建 CLI 后，实际运行不带 baseline 的部署自检，得到 7 PASS、1 FAIL、6 WARN、4 INFO。唯一 FAIL 是默认身份注册表包含两把公开测试公钥。引擎此前已经拒绝把它们认作可信身份，但默认模板仍要求部署者删除这两把无用的公钥，形成反复出现的配置陷阱。

本次移除默认三张身份卡中的公钥字段，保留名称、任务范围与原有可选认证设置。未配钥的卡片为 `NoKeyOnRecord`，不能成为 `Verified`；开启强制认证会拒绝这些会话。没有替用户生成、选择或配置真实身份。历史模板原文加一行说明后存入 `eval/fixtures/public-agent-registry.yaml`，公开密钥拒绝表及成功认证、伪造、重放和任务越权测试保留。

自检改为准确报告“0/3 张卡配置了公钥”，并注明不在已知公开密钥表不等于证明私钥保密。默认结果为 8 PASS、0 FAIL、6 WARN、4 INFO；基线不变量现在要求零 FAIL，同时必须保留三张未配钥身份和可选认证的说明，不能通过重写基线接受新的失败。发布脚本只更新解释文案，strict 的生产自检和其他门禁保持。

六项警告分别涉及可选 Agent 认证、适配器公钥、应用签名者、CLI 审计签名、演示许可证及本机 Linux 内核约束不可用。这里的 CLI 自检没有加载固定 App 的审计签名配置，不能据此认定 App 的审计也未签名。
