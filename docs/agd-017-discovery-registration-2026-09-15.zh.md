# AGD-017 完整发现清单与运行身份登记

日期：2026-09-15。状态：发现登记组件已实现并完成官方服务实操；完整第三方代理仍进行中。接续[隔离启动记录](agd-017-service-isolation-2026-09-15.zh.md)，不缩小原 32 项开发计划，不把本节组件计为 AGD-017 完成。

## 登记的数据来自哪里

`NodeService::discover` 从已冻结的实际包启动一个空工作区的只读隔离会话，完成 MCP 2025-06-18 握手和工具发现。握手及清单共享最多 30 秒时限；发现结束后关闭服务并核实容器不存在，才交付 `ServiceDiscovery`。这个对象不支持反序列化或外部构造；宿主登记入口直接消费其中的实际观测。

登记名称和展示用包版本由宿主配置，包 SHA-256 来自冻结字节，执行 SHA-256 来自实际镜像、入口、参数及已有启动限制。服务版本从实际握手结果取得。完整初始化结果、清单顶层元数据和每个工具的原始定义都进入摘要及独立复核；初始化 `instructions` 和服务自报信息仍是数据，没有批准权。

原登记的四项索引字段继续保留，并与工具原始定义逐项校验。旧内建清单不输出新增的可选字段，已有清单和描述摘要编码保持不变；旧审计记录可以继续恢复。新持久事件只保存运行摘要和原有身份／内容摘要，不写入下游标题、说明、Schema 或初始化原文。

## 完整字段与支持范围

保留 `name`、可选 `description`／`title`、`inputSchema`、可选 `outputSchema`／`annotations`／`_meta`。描述缺失与空字符串保留各自原貌；标题、注解、输出定义、元数据中的隐藏字符及数组顺序变化都会改变摘要。递归对象键排序不改变同一内容的身份。

当前官方 SDK 在协商 2025-06-18 时也返回 `execution: {"taskSupport":"forbidden"}`。这一明确的同步声明完整保存并纳入摘要；`required`、`optional`、空值、额外执行字段和其他未知工具字段明确拒绝。没有启用异步任务或升级现有客户端协议。

沿用原 48 KiB 完整登记上限、64 个工具、32 字节 ASCII 名称。单个原始工具定义最多 32 KiB，输入／输出 Schema 各最多 16 KiB，标题／描述最多 4096 字节；结构继续限制深度和节点数量。分页、无效类型、重复工具、原始定义与索引不符均拒绝。这里验证登记形状，不宣称已经实现代理调用参数或返回值的完整 JSON Schema 校验。

独立复核后，登记组件可生成带名称空间的公开描述。下游 `_meta` 放入宿主回执中的 `downstream_metadata` 数据区，不能覆盖宿主的登记绑定或 `instruction_authority`；其原始内容仍完整参与摘要和复核。工具的只读提示不授予工作区权限，也不省略逐次动作批准。主网关目前仍只路由内建工具，第三方 `dispatch_supported` 保持 `false`。

## 清理确认修正

真实发现超时负例暴露出原实现的提前返回：删除命令报错时，没有继续查询实际容器状态便标记清理未知。修正后只发送一次精确删除，再进行最多 2 秒、间隔 40 毫秒的只读查询，以容器确实不存在为完成条件；没有重发协议请求或删除命令。删除命令本身仍有 10 秒时限。

查询失败、结果截断或期限内仍存在容器，仍保持清理未知：启动器与共享副本拒绝新操作，保留冻结包。原始失败留下的故障证据不被后续成功覆盖。发现成功也只代表空工作区阶段已结束，不能当成有数据服务的运行批准。
