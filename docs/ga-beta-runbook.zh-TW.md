# 14 天 Beta 運行手冊

## 開始條件

RC 技術閘門已通過；六端 commit、版本、build ID 與 SHA-256 已凍結。先記錄 Beta 群體、同意／退出、資料最小化、指標口徑、停止閾值與值班人，並演練回滾、功能開關、[事故](incident-response.zh-TW.md)及[支援](support-runbook.zh-TW.md)流程。

## 計時與每日檢查

以唯一 RFC3339 UTC 時間開始；同一候選系列需連續觀察至少 `14×24` 小時。安全、隱私或核心判決變更、不相容重打包、Sev-0/1 或關鍵遙測中斷會重置時鐘。純文件例外需要 Release+QA 書面理由。

每日按渠道檢查活躍數、安裝／升級／首啟、崩潰／無回應、保護可用性、誤報／漏報、確認佇列、觀測權限、審計完整性、隱私訊號及支援工單。診斷材料必須去除 PII 和憑證，原始資料留在受控系統並遵守保留期。

## 停止與通過

Sev-0/1、未受控安全／隱私擴大、無法回滾或關鍵遙測缺失都立即停止。通過要求 Release+QA 複核完整日誌、無未結 Sev-0/1、預定閾值全數達標，並產生 BT1–BT4 唯一證據。CLI 只驗 14 天與材料形狀，不替代指標真實性及人工審查。
