# iOS 风险提示的名称与键盘焦点修正

日期：2026-09-17。基线 `776c8c18ab3966cabddda434c842fe5280985bae` 加本批修改。App 与 Extension 保持名称和 Bundle ID，构建号从 2 递增至 3。本轮按原验收 I6 修正可复现的内容脚本问题，**不代表真实 iPhone／iPad 的 VoiceOver、动态字体、Safari 扩展或 TestFlight 已通过**。

## 问题与修正

在旧内容脚本的真实 Chromium DOM 中，以键盘触发付款提示：无障碍树的对话框名称为空；Tab 离开提示，活动元素变成页面主体；Escape 关闭后也没有返回付款控件。页面没有产生付款请求，但键盘和读屏用户无法可靠定位与继续操作。四个新增脚本回归在旧代码全部失败，旧源码和失败日志均保留。

- 对话框在封闭阴影根内关联本地化标题和解释，读屏树能取得名称与描述。
- Tab／Shift+Tab 留在唯一的关闭键；Escape 只关闭当前最上层提示，不继续传给网页。关闭键或 Escape 返回此前仍连接的焦点，支持开放阴影根中的原控件。
- 不同风险重叠时按层处理焦点；原控件已被移除时不强行恢复。没有增加放行、自动点击或提交路径，风险同步阻断和原审计语义保持。

## 验证
