# Capability matrix (generated from source)

This file is generated by `scripts/gen-capability-matrix.py` from the source tree. **Do not edit it by hand** — a repository invariant under `cargo test` regenerates it and compares byte for byte; drift is red. Wherever a hand-written document (README, store copy, release notes) states what a platform observes, how many tests exist, or which version is built, this file is the reference. It records mechanical facts, not product promises: a platform "emitting" an event kind means the code path exists; whether it works on a real device is answered by the `acceptance-*.md` checklists.

The table lists the kinds each platform's source **actually constructs or reports**; a kind absent from a row has no source on that platform, whatever the copy says.
