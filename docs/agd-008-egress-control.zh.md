# AGD-008：受控本机服务出口与凭据代理

日期：2026-09-10。状态：出口代理与持久日志模块专项通过；桌面接线及同候选联合验收由主任务汇总。本文件不把模块测试计作 AGD-008 全路径或完整 M1 通过。

## 支持范围

任务代码继续在 `--network=none` 的工作区快照容器运行。需要联系本机服务时，可信宿主通过出口代理发出请求，任务不获得网络命名空间、宿主控制端口、凭据文件或代理登记权限。

当前只支持宿主明确登记的规范地址 `http://127.0.0.1:<端口>/<准确路径>`，每个登记项固定方法、用途、可发送数据范围、响应方式和最长时间。拒绝 DNS 名称、IPv6、其它 IPv4 写法、HTTPS 与其它协议、路径歧义、查询串和重定向；这是准确本机服务允许清单，不是域名隔离或全机防火墙。生产远程服务的 TLS、证书、DNS 地址绑定及其验收仍需独立完成。

本机模型服务属于操作者明确选择的接收者。代理能够限制发给它的请求，不约束该服务自身的文件或联网行为。未经过受控任务入口的终端、其它客户端和外部 MCP 服务不因此获得隔离覆盖。

## 执行与授权

1. 宿主构造不可变 `LocalService`，登记本机服务并提供全部当前控制端口的拒绝清单。登记服务和签发授权都是 Rust 宿主接口，不是 MCP 或 HTTP 客户端接口。
2. 宿主注册 `SessionContext`，包含会话编号、代次和期限。公开模型列表探测使用 `Public`；工作区正文发送必须由独立任务范围允许 `Workspace`；`Sensitive` 和 `Unknown` 拒绝。
3. 宿主生成 `EgressRequest` 并签发短期 `EgressGrant`。完整请求、实际目标、方法、用途、数据范围和响应方式参与摘要，授权同时绑定会话、代次、摘要、单次随机值和期限。
4. 使用授权时立即消费；正文替换、跨会话、过期、已撤销及旧代次均不能产生新请求。一次调用失败或结果未知也不能复用原授权。同一代理实例不能复活已经登记过的会话编号。
5. 派发前持久记录意图，失败则不创建连接并关闭实例。网络连接前、写入期间和读取期间检查取消与撤销。已写入字节后的超时、取消、断连或格式不明返回 `unknown`，不声称零副作用，不自动重试。
6. 完成后持久记录真实终态。此时审计失败会隐藏响应、保留是否已经发出并关闭实例；已发出的结果为 `unknown`。

授权最长 60 秒，服务可以进一步收紧；会话最长 24 小时。每个代理实例最多 64 个服务、128 个会话编号和 1,024 份待用授权。请求包络最多 2 MiB，HTTP 头最多 16 KiB，响应最多 1 MiB。该限制是当前支持边界，超限会明确拒绝。

`data_class` 只能由可信读取与任务范围逻辑赋予，不能根据 Agent 自报的标签放行。此模块并不通过内容字符串推断所有秘密，也不声称恢复模型内部的数据来源；桌面发送范围与敏感内容检查的真实接线需要在联合验收中核对。

## 凭据与 HTTP 行为

凭据只由宿主调用 `LocalService::with_bearer` 放入代理内存，再向准确登记的上游注入 `Authorization`。请求对象不接受任意 URL、头、凭据、批准或会话字段。代理不读取账号环境、不启动子进程，不继承 HTTP 代理变量。

有凭据服务强制使用 `StatusOnly`，任务只取得固定成功或失败结果，不能取得响应正文、响应头、HTTP 状态数字或响应正文摘要。这同时避免明文和编码形式的凭据回显。无凭据模型服务可以返回经有界 HTTP 解析的 JSON；非成功状态只返回 HTTP 状态供宿主判断，例如模型状态端点返回 404/405 后明确请求另一个已登记端点。不会跟随 3xx，也不会自动重试原动作。

实际网络测试必须覆盖重复长度、长度与分块并存、额外正文、截断、压缩、分块扩展、尾部字段、协议升级和过大响应。响应错误只返回固定错误码，不把上游错误正文或系统错误详情交给任务。

## 持久日志

`DurableEgressJournal::open(&Path)` 使用现有 `AuditStore`。调用者先创建属于当前宿主用户、不可被其它用户写入的专用目录，再使用规范绝对路径打开日志。日志和锁文件为 `0600`，拒绝符号链接、硬链接和不安全权限；持有独占锁防止两个存活实例互相进行崩溃恢复，记录前核对文件及父目录身份。

SQLite 明确使用 `FULL` 同步和 `fullfsync`，打开时核对哈希链。没有对应终态的派发意图在重启时追加一条 `unknown`，其中是否派发为未知，不发出任何补偿或重试请求。请求、响应及凭据原文不入库，只保存宿主随机编号、固定枚举、字节数和摘要。日志公开字段也会重新校验，不能借字段塞入任意原文。

本版出口日志明确为未加密、未签名的宿主私有摘要日志，不自动读取环境中的加密材料。哈希链用于发现损坏和不一致，不承诺抵抗能重写整个日志的宿主攻击者。该目录不得进入隔离快照。已开始的外部动作不会因审计失败而自动撤回。
