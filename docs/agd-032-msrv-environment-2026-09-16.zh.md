# AGD-032 前置修正：最低 Rust 版本不再继承新版编译器

日期：2026-09-16。源码基线：`9df7323f3f1821849224928132c7bec8dd57f0e7`。本批修正实际发现的门禁环境问题；不是正式发布验收通过。

`scripts/bootstrap-rust.sh` 为正常开发固定 Rust 1.95.0，同时导出 `RUSTC`、`RUSTDOC` 和 `RUSTUP_TOOLCHAIN`。旧 `make check-msrv` 只把 Rust 1.87 的 Cargo 目录放到 `PATH` 前面，Cargo 仍会读取调用方指定的新版编译器，因此经启动脚本执行的“最低版本检查”可能实际使用 1.95。前批已明确清除这两个变量的 1.87 验证保留原证据；本问题不能反推独立 CI 的所有 MSRV 结果都是无效的。

修正后，目标明确选择 1.87.0 的 Cargo、rustc、rustdoc 和工具链环境；工具路径查询失败立即返回，不再回落到调用方的 Cargo。没有更改最低版本声明、Cargo 锁文件或产品行为。

## 验证

- 新增行为回归实际执行原 Makefile 配方，注入错误的编译器和工具链环境。修正前确实失败并记录调用方路径；修正后环境覆盖、缺少工具链、工具路径查询失败三个场景通过。该回归接入已有仓库不变量测试，CI 会继续运行。
- 不手动清除新版变量，直接运行 `DEVELOPER_DIR=/Library/Developer/CommandLineTools scripts/bootstrap-rust.sh -- make check-msrv`；**1,535 项通过、17 项忽略**，目标输出 `MSRV 1.87 PASS`。保存的 Cargo 编译器信息确认为 **rustc 1.87.0**，不是仅依据目标名称判断。
- Rust 1.95 的全仓、全目标 Clippy 与格式检查通过，脚本和前端语法检查通过。三个夹具场景属于已有测试中的覆盖，不与全仓测试数重复累加。
- 固定 App 023 没有重新构建，91 个文件保持；未更改签名、权限、存储格式或发布门槛。
