# 桌面端使用說明

## 先區分三條防護路徑

| 路徑 | 能做什麼 | 不能據此宣稱什麼 |
| --- | --- | --- |
| 桌面觀察 | 偵測已呈現的視窗狀態、提醒並記錄 | 不能撤銷已發生動作，也不保證事前攔截 |
| Chrome / Edge 擴充功能 | 阻擋匹配的點擊、陷阱表單和特定付款形狀請求 | 不涵蓋所有網站與動作；沒有網頁內允許一次或例外 |
| MCP 工具閘道 | 對實際經過閘道的呼叫允許、拒絕或等待確認 | 智慧代理直接執行可繞過；握手不等於用戶端接入成功 |

首個 GA 擴充功能獨立運作，沒有 Native Messaging；桌面 App 不會讀取擴充功能狀態、代替瀏覽器授權或自動合併全部記錄。

## macOS 新工作區

2026-09-06 的 macOS 改版提供**總覽、主動防護、活動記錄、防護設定、說明與診斷**。Windows 本輪保留原版面，沒有宣稱已同步新介面。

### 第一次開始桌面觀察

1. 在總覽檢查「輔助使用」與「加密活動記錄」。輔助使用是必需權限；螢幕錄製只增加可選像素與浮層偵測，只有錄影權限不足以開始。
2. 從「防護設定 → 桌面觀察」開啟系統設定，核對總覽中的**目前應用程式檔名**和診斷中的完整路徑。
3. 使用者自行授權，回到 App 重新偵測。回到前景也會進行唯讀檢查，不會自行授予權限。系統要求重新啟動時，結束並開啟同一份 App。
4. 必需權限及加密記錄就緒後，選擇任務並開始守護。任務選擇儲存在本機，於下一次會話生效，不改變已開始的會話。
5. 結束守護會停止會話及觀察器。狀態依會話、觀察器、有效心跳和記錄可寫性計算，不把按過按鈕當成成功。

驗收渠道固定為 `AgentGuard Test.app`，識別碼 `com.agentguard.desktop.macos.acceptance`。舊 Production/Recovery App 的權限不是目前 App 已授權的證據。固定名稱可減少混淆，**但不能讓 ad-hoc 簽署跨重新編譯維持身分**；正式簽署與公證仍是發佈門檻，不應批次重設系統權限。

加密記錄未就緒時，依專用恢復提示處理；鑰匙圈視窗由使用者操作。歷史資料只經明確確認的保留歷史升級程序，不刪除原始資料庫或用空資料庫假裝恢復。

### 四個設定標籤

- **桌面觀察**：實際權限、系統設定、重新偵測與下一次任務。
- **風險處理**：分開說明桌面、擴充功能和閘道的處置；情報版本及重新載入。閘道預設確認時間為 120 秒，未回應拒絕；這是預設說明，不是外部程序即時設定回讀，也不是可儲存的開關。
- **隱私與記錄**：本機加密狀態、摘要匯出與恢復說明。桌面與擴充功能記錄分開，不提供沒有恢復保障的全部清空。
- **一般**：繁體、簡體、英文、跟隨系統；淺色、深色或跟隨系統外觀。偏好保存在本機，失敗時提示，不修改安全策略。

## 主動防護：接入與驗證

### Chrome / Edge

從「主動防護 → 瀏覽器防護 → 安裝與驗證」開啟隨附擴充功能及無害驗收目錄。這是本機測試包，不是已上架商店版本。

使用者在可信的瀏覽器擴充功能管理頁檢查權限並安裝啟用。依 README 在 `127.0.0.1` 提供測試頁；直接雙擊 file:// 不算 HTTP 網頁驗收。普通按鈕計數應增加；「Pay now」只改變本機頁面計數，不會付款或連線支付服務，匹配阻擋生效時付款計數應保持 0。再核對擴充功能自己的記錄。

桌面端沒有狀態通道，因此維持「請在瀏覽器驗證」，不自動亮綠燈。此版沒有網頁內放行、動作重播或網站例外，單一範例通過也不代表所有付款均可阻擋。

### 智慧代理工具閘道

從「主動防護 → 智慧代理工具閘道 → 設定接入」檢查閘道並產生設定。App 只啟動自己的隨附程序，進行 MCP 握手與工具列表查詢，隨後結束檢查程序；不呼叫工具、不修改用戶端設定。

產生的通用 stdio MCP 設定指向目前安裝包，不包含確認權杖，也不預設授予整個使用者目錄。使用者選定實際 MCP 用戶端、保留原設定後合併服務；需要寫入時先核准最小任務與目錄。重新啟動用戶端後，以無害輸入驗證允許、拒絕、需確認及逾時，並核對實際副作用。App 握手成功仍不代表用戶端已接入。

**桌面閘道確認現已接入。** 在主動防護頁「閘道待確認操作」輸入目前程序的本機連接埠及 32 位確認權杖。權杖從該程序的本機 stderr 日誌取得，只填入 App，不傳送至網頁、聊天或報告。舊版閘道沒有狀態介面時需更新。

核對目前編號、完整操作、風險判據與期限。可直接拒絕；批准前需勾選已核對，且僅批准目前請求。新請求不繼承舊勾選或回執。批准回執不等於工具執行成功，請到發起呼叫的用戶端核實結果。

送出後清空權杖輸入，僅在目前後端連接的記憶體保留，不寫入設定。中斷或結束 App 後不自動重連；連接故障或過期會停用批准。手動中斷不是立即拒絕，但無人回答時閘道最終逾時拒絕。回執不明不會自動重試，可能已執行，須到呼叫端核對。

此通道與桌面「繼續監控」獨立，只連接一個閘道程序；不驗證特定用戶端、不自動合併閘道記錄至桌面活動頁，也不繞過 `Block` 判決。見[工具閘道技術說明](工具网关.md)。

## 記錄、診斷與驗收界線

活動頁顯示桌面摘要，總覽不顯示外部正文；摘要匯出在本機完成並回報路徑。建置身分、實際 App 路徑、隔離驗收資料目錄及開發者控件集中在「說明與診斷」，路徑預設收合。

桌面自我測試使用本機假事件，不連線、不付款，只證明規則、提醒及記錄鏈路，不證明觀察器已工作或外部動作已阻擋。請到原應用程式核實結果；暫停只影響後續受保護處理。

編譯、介面測試及真實啟動不代表可發佈。實際授權後的連續觀察、正式簽署、公證、隔離安裝、用戶端接入與確認流程仍需獨立證據；Windows、Android、iOS 及各瀏覽器商店各自驗收。見[發佈證據](release-evidence.zh-TW.md)。
