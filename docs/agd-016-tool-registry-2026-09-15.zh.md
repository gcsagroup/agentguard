# AGD-016 工具登记与变更复核

日期：2026-09-15。状态：**首批工具登记、变更复核和实际执行绑定已完成。** F13 按用户要求暂缓、未验收；完整原 M1、整个开发计划和发布仍未通过。

## 本次行为

宿主记录工具服务、名称空间、包身份、服务版本，以及描述和参数定义的摘要。每次实际动作都绑定完整清单摘要、单工具摘要和本次登记代次。描述、参数定义、包、版本、新增或删除工具发生变化时，旧认可和旧动作批准失效；恢复旧版本也不能复用旧代次。

外部服务首次提交的清单始终为 `pending`。独立操作者查看准确清单后才能认可或拒绝；描述中的“已批准”、角色边界文本或扫描结果都没有认可权。名称空间一旦归属某服务，即使撤销也不能被另一服务接管；外部服务不能占用宿主保留身份或声明宿主控制动作。

| 内建服务 | 登记范围 | 公开入口 |
| --- | --- | --- |
| `agentguard-gateway` | 5 个文件／命令工具、开始和结束会话 | 7 个 MCP 工具 |
| `agentguard-protected-browser` | 5 个浏览器工具、宿主 HTTP 请求 | 5 个 MCP 工具；HTTP 动作不直接公开 |
| `agentguard-host-control` | 回写、暂停、恢复、停止 | 仅独立操作者通道 |

全新登记库中，只有宿主编译代码声明的三组内建服务可以首次生效。已有登记库遇到新宿主包、版本或工具清单时仍进入 `pending`，不能以“内建”自动认可升级。外部候选在本轮即使经过认可，也明确显示 `dispatch_supported: false`；第三方 stdio／远程代理属于 AGD-017，尚未交付。

## 包与持久恢复

内建包身份使用实际宿主可执行文件的 SHA-256。宿主编译时嵌入 53 个第一方浏览器／扩展资源；启动浏览器前逐文件核对实际字节，将同一批已核对字节复制到私有冻结目录，并从冻结副本运行。来源文件在核对后被替换，不会改变已冻结的运行内容；首次发现包字节不符就拒绝启动。浏览器进程实际返回的 `tools/list` 还须与宿主声明逐值一致。

这项包绑定覆盖宿主和明确列出的第一方资源，不是 Node、Playwright、Chromium 全部依赖的供应链认证。生产入口为 `cli.mjs`；既有 `host-resolver-probe-actor.mjs` 是单独编译登记、显式指定的诊断入口，不会被当作普通工具发布。

登记日志独立保存在执行审计旁的 `<audit-db>.tools.db`。日志只保存类型化身份、摘要、状态和代次，不保存描述、参数定义正文或复核随机数。恢复时验证哈希链、合法状态迁移和代次唯一性；拒绝双写、空认可和旧代次复用。写入失败后停止使用登记，不能回退到内存认可。当前最多 64 个服务、4096 个登记事件，达到上限后停止新动作，不能删库来冒充连续审计。

重启后，已保存摘要仍需本进程重新观测实际清单。内建清单由宿主重新声明；外部候选必须重新提供清单，与持久摘要相符后才恢复已保存认可。旧复核凭据不持久化，不能跨重启使用。规范化以解析后的 JSON 为准，递归排序对象键和工具名称；描述中的 Unicode 字符及参数定义数组次序保留，不宣称通用 RFC 8785 或原始 JSON 文件字节认证。

## 独立操作者接口

以下路径沿用现有本机控制连接的 Bearer、Host 和 Origin 校验，不接受 MCP 方法调用。控制连接文件仍位于任务授权范围之外。清单正文上限为 48 KiB，单工具说明 4 KiB、参数定义 16 KiB；请求整体有界读取，复核有效期 120 秒。

| 路径 | 方法与正文 | 用途 |
| --- | --- | --- |
| `/registry/status` | GET | 查看登记状态和本进程是否已观测 |
| `/registry/observe` | POST `{manifest}` | 外部候选首次或再次观测；不授予认可 |
| `/registry/review` | POST `{service_id}` | 返回准确清单、摘要、复核标识、随机数和到期时间 |
| `/registry/decide` | POST `{service_id, review_id, review_nonce, manifest_sha256, approve}` | 对本次准确清单作独立决定 |
| `/registry/revoke` | POST `{service_id, registration_id}` | 撤销当前登记 |
| `/registry/refresh` | POST `{service_id}` | 使用本进程已实际观测的清单重新登记被撤销项目 |

改变已认可的清单或撤销登记会暂停会话并取消待批准动作。重新认可不自动恢复任务；操作者仍须明确恢复并获取新会话标识。文件、浏览器、HTTP 和宿主回写分别在执行前检查登记；旧差异预览不能复用。已派发动作仍按既有撤权与结果核对规则处理，不承诺撤回已发生的外部效果。
