# 5% → 25% → 100% 擴量手冊

擴量只針對同一凍結 artifact-set。六渠道各有獨立開關、暫停與回滾，不得借用其他渠道的完成狀態。比例、健康閾值、最短觀察期和決策者須在 5% 前寫入受控發佈單。

1. **5%**：核對真實渠道產物摘要，抽驗新裝、升級、首啟、最小保護及回滾。
2. **25%**：只有在 5% 觀察窗完整、資料可用、無停止事故且 Release+Operations 核准後進入，重做健康和支援檢查。
3. **100%**：只有在 25% 穩定且五方核准仍有效時進入；全量後仍持續值班、渠道可用性與事故監控。

Sev-0/1、簽署／更新鏈失敗、隱私越界、核心保護不可用、指標缺口或超閾值都立即凍結並依[事故手冊](incident-response.zh-TW.md)回滾。RO5/RO25/RO100 各保留時間、比例、artifact-set、健康查詢、事故、支援摘要、決策人及回滾證明。CLI 只驗時間順序與候選綁定，外部事實仍需受控複核。
