# AGD-017 服务包冻结与隔离启动

日期：2026-09-15。状态：隔离启动组件已实现并完成本轮验证；完整第三方 MCP 代理仍进行中。本文接续 [stdio 传输记录](agd-017-mcp-proxy-2026-09-15.zh.md)，没有改变原开发计划的任务和验收范围。

## 服务实际从哪里运行

`FrozenPackage` 将选定服务包的全部条目复制到私有目录。普通文件的摘要来自实际复制的同一批字节，不使用目录名、npm 锁文件或服务自报版本代替。文件名、空目录、文件大小、可执行位和符号链接目标都进入登记摘要；不静默跳过 `.bin` 等目录。启动前再次核对完整冻结副本。

复制通过目录句柄及 `openat`／`O_NOFOLLOW` 进行，检查打开前后的文件身份，以及读取前后的长度、时间和链接数。只接受指向包内普通文件、且路径不经过其他链接的相对符号链接；拒绝包外、绝对、悬空、目录链接及链接链。硬链接、凭据路径、设备、FIFO 和 Socket 均拒绝。私有副本中的目录是 `0500`，文件是 `0400` 或 `0500`，不继承源目录的写权限。

包树最多 20,000 个条目、512 MiB、32 层目录，包内路径最多 1024 个 UTF-8 字节。复制按 64 KiB 堆缓冲区读取，不让深层目录累计大栈帧。摘要沿用 AGD-016 的递归键排序，前缀为 `agentguard.tool-registry.mcp-package.v1\0`；不声明通用 RFC 8785 兼容。实际运行身份另外绑定镜像、入口、参数、容器限制和编译进宿主的启动门禁，前缀为 `agentguard.tool-registry.mcp-node-execution.v1\0`。工作区挂载和用户身份使用独立的 `mcp-node-scope` 域。

`NodeService` 只接受本地已有的 Linux 镜像 SHA-256，拒绝镜像声明的额外卷。它固定 Node 入口，不运行任意宿主命令；入口必须是冻结包内普通文件，启动参数最多 64 个、总计 8 KiB，并拒绝控制字符。本轮复用既有镜像 `sha256:7de5789da80158e418d22bf911ea3829aa1abdeb2338dd556dc99b13c89d8490`，没有创建镜像或卷。

## 发现和授权运行的区别

| 阶段 | 容器能接触的内容 | 工作区写入 |
|---|---|---|
| 工具发现 | 只读冻结包、空的只读 `/workspace`、镜像与有限临时目录 | 实际写入被只读挂载拒绝 |
| 授权后的服务运行 | 只读冻结包、已有隔离执行器创建的授权副本 | 仅按既有副本的读写权限运行，宿主原件不挂载、不自动回写 |

两个阶段产生不同的服务进程、会话标识及范围摘要。同一个启动器只允许一个活动会话；工作区副本必须与服务使用相同镜像和 Docker 连接目标。运行回执只是宿主的身份记录，不是批准令牌，也不能证明工具已经执行成功。

容器固定禁网、只读根文件系统、非 root 用户、移除全部 capabilities、禁止提升权限、64 进程、256 MiB 内存（禁止额外 swap）、1 CPU 和 16 MiB 临时目录。镜像健康检查被禁用，不发布端口、不挂 Docker Socket。Node 获得清空后的四项环境变量：`PATH`、`HOME`、`TMPDIR`、`LANG`。

第三方 JavaScript 启动前，宿主编译的 Python 门禁在容器中核对 Linux、实际 UID/GID、NoNewPrivs、seccomp 和 capabilities；不满足时退出，不降级为原生执行。实际测试范围是上述固定镜像及当前本地 Docker 引擎，不把任意镜像或其他平台视为已验收。

第三方程序在初始化时也可能执行代码。发现阶段没有工作区数据或写权限；授权运行阶段的程序可以改变其已获授权的私有副本，包含启动期行为。因此不能把每次 MCP 调用日志称为其全部内部行为日志，也不能省略宿主最终差异预览和回写批准。

## 超时、退出和清理未知

关闭服务先关闭 stdio，随后按本次随机容器名删除容器，并再次查询引擎确认该容器不存在。不会把 Docker 客户端退出等同于容器结束。实际测试还从容器外核对：服务派发后超时没有重发，清理完成后子进程写入的心跳停止。

清理结果未知时，启动器及共用工作区副本保持故障状态，拒绝新会话／新执行；冻结包和待核查的临时挂载目录保留，不能在释放对象时提前删除。组件不会自动清理别的容器、镜像或卷，也不会因重新尝试同一对象而恢复健康。测试中的连接丢失只修改自有测试对象的连接地址，未中断用户 Docker 引擎；随后使用原连接精确删除并核实该自有容器，故障状态仍保留。

这些状态目前属于启动器和副本实例。跨网关重启的执行审计、恢复及操作者控制还须在产品代理接线中完成，不能把实例内故障状态当成持久恢复闭环。
