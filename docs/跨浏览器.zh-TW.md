# 首個 GA 的跨瀏覽器範圍

> 結論：首個 GA 只支援 Chrome 與 Edge，兩者共用同一個 Chromium ZIP。Firefox 僅保留原始碼原型，不封裝、不提交、不作為首個 GA 驗收門；Safari 是獨立產品線。GA 瀏覽器套件停用 Native Messaging。

## 首個 GA 支援範圍

| 項目 | Chrome | Edge |
|---|---|---|
| 發布套件 | `agentguard-extension.zip` | 與 Chrome 共用同一 ZIP |
| 頁面掃描 | `document_start` 的 isolated content script；瀏覽器允許注入的各 HTTP(S) frame | 同 Chrome |
| 高風險 DOM 動作 | 執行前 block-only；不在網頁內放行 | 同 Chrome |
| 靜態付款 DNR | 預設啟用；按聲明的關鍵詞、HTTP(S)、非 GET/HEAD 與資源類型硬擋 | 同 Chrome |
| Native Messaging | GA manifest 不含 `nativeMessaging` | GA manifest 不含 `nativeMessaging` |
| 驗收 | Chrome 商店候選獨立留證 | Edge 商店候選獨立留證 |

Chrome manifest 的 `minimum_chrome_version` 與所用 DNR 能力一致。Edge 使用相同的 `chrome.*` API、manifest、內容腳本與規則。共享原始碼與 ZIP 不取代兩家瀏覽器各自的安裝、升級、權限提示與執行時驗收。

## 共同安全邊界

- 瀏覽器允許注入的 HTTP(S) frame 內，符合條件的付款／轉帳點擊與隱私陷阱個資提交會同步阻擋，不重播原動作。
- 頁面內提示只是可被網頁刪除、遮蔽或仿冒的資訊層，不是授權 UI。
- 使用者若確實需要繼續，只能從 `chrome://extensions` 或 `edge://extensions` 停用或移除保護，再自行重做操作；網頁內沒有「允許一次」或暫時例外。
- 靜態 DNR 是獨立 block-only 網路層：僅涵蓋規則列出的付款路徑關鍵詞、HTTP(S)、非 GET/HEAD，以及 `xmlhttprequest`、`ping`、`main_frame`、`sub_frame`。
- 靜態 DNR 亦明確涵蓋規則列出的逐位元組百分號編碼路徑變體，以及查詢鍵 `op`、`action`、`operation` 等於付款標記的形狀；它不檢查 body，也不聲明涵蓋 body-only、自訂別名、未列編碼／混淆形式、任意查詢鍵或值、WebSocket/WebTransport 或其他資源類型。
- 頁面 `postMessage`、舊 decision/scope 訊息和一般頁面 DOM 都不是信任根。

精確關鍵詞、字元邊界與負向範圍見[瀏覽器執行前阻斷](浏览器执行前阻断.zh-TW.md)。

## Firefox：原始碼原型，不是首個 GA 產品

儲存庫保留 `manifest.firefox.json` 與相容性原始碼，目的是為後續研發保留起點，不代表發布支援：

- `package-store.sh --firefox` 必須拒絕執行，不得產生 Firefox 商店套件；
- 首個 GA 的 release gate、驗收清單與上線結論不得要求或引用 Firefox PASS；
- Chrome / Edge 的 E2E 不能當作 Firefox 執行時證據；
- Firefox 原型檔案存在、版本一致或結構測試通過，都不能升級為「支援 Firefox」的聲明。

Firefox 若進入後續版本，必須另行完成 manifest、DNR 行為、權限、商店封裝與真實瀏覽器驗收，屆時再更新支援矩陣。

## Native Messaging：GA 停用

GA manifest 明確不申請 `nativeMessaging`，Chrome / Edge ZIP 也不含 Native host。儲存庫可保留 host 原始碼、安裝範本與實驗性連線程式碼，但它們不是首個 GA 執行路徑、商店能力或驗收依據。首個 GA 不聲明 Native 判決、動態主機阻斷、host 通知或本機稽核鏈。

## Safari：獨立產品線

Safari Web Extension 透過獨立 Xcode 應用程式殼、Extension target 與 Apple 簽署流程交付，不使用此 Chromium ZIP，也不屬於本文件定義的首個 GA 瀏覽器範圍。

## 驗證邊界

`make check-extension-gate` 應驗證 Chrome / Edge 套件、block-only DOM 行為、靜態 DNR、GA manifest 無 Native Messaging，以及 Firefox 封裝被拒絕。自動化通過仍不是真正的 Chrome / Edge 商店候選瀏覽器 PASS；最終狀態以各自非歷史、與候選產物綁定的新證據為準。
