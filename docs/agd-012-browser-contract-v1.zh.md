# AGD-012 专用浏览器动作契约适配

2026-09-10 后续：统一宿主 CLI、实际 HTTP 转发、持久回执与受限进程启动已另行实现，见[统一宿主接入](agd-012-unified-host.zh.md)。以下保留 2026-09-09 的原始范围与验收结论，不把当时的格式适配追记为完整统一会话。

日期：2026-09-09。结论：**动作与批准格式适配已实现并通过本机测试；统一桌面宿主会话入口仍未完成，AGD-012 整体为部分完成。**

## 本次改变

- 专用浏览器使用契约 1 的 `ActionSnapshot`／`ApprovalBinding` 字段：会话、动作、请求编号、工具身份和版本、最终 URL、HTTP 方法、完整正文、已捕获请求头、策略范围版本、期限及动作／批准随机值。对象递归冻结，批准不能替换目标或正文。
- 回答必须提交 `id`、`action_sha256`、`approval_nonce` 与布尔决定；批准和拒绝都核对当前绑定。旧 `digest` 协议、错误随机值、错误摘要、重放及失效会话被拒绝。待确认项在决定时同步删除；执行前再次核对连接、页面、Agent 连接代次、策略与期限。
- 请求头只调用一次 `allHeaders()`，缺失 Cookie 的空值在批准前确定；冻结副本用于批准摘要和实际发送。捕获后的 Cookie 变化不会偷换此次请求。无查询 GET/HEAD 仍沿用既有放行策略，不表示没有远端业务副作用。
- 控制页保留完整目标、正文与勾选入口，并可展开查看会话／工具／策略／摘要和请求头。正文按文本呈现；同编号内容改变也清除勾选，缺完整绑定禁用批准。Agent 操作令牌和控制令牌继续分开；Agent 状态和内存事件摘要不含绑定随机值、请求头和正文。

## 验证

浏览器测试共 **37 项通过**：原有 31 项及新增 6 项。合成的真实 Chromium／HTTP 对照确认旧协议、随机值错误、目标摘要和正文摘要替换均为服务器零提交，随后正确批准原始正文与已捕获 Cookie 恰好提交一次，重放为 HTTP 409。原有取消、拒绝、超时、断连、客户端崩溃与扩展阻断回归继续通过。

共享无害 JSON 样例包含完整正文、数字键和补充平面 Unicode 键；Rust 独立验证反序列化、规范 UTF-8 字节、SHA-256 与批准匹配。JS 只接受安全整数和良构 Unicode，使用 UTF-8 键顺序；本实现不是通用 RFC 8785。对应样例：[action-contract-v1.json](../apps/protected-browser/fixtures/action-contract-v1.json)。

另外使用 Computer Use 实际操作本地控制页，核对正文里的 `<b>` 仅作为文字显示，展开实际绑定，确认勾选前按钮禁用、勾选后批准当前一条，再核对 HTTP 200 回执和本地服务器 **1 次原始正文提交**。最后断开控制并关闭临时服务与标签。该操作使用合成令牌与无害本机站点，无外部业务行为。

输出：`.artifacts/agd-browser-contract-v1/`；桌面和窄屏截图来自实际 Chromium，位于 `apps/protected-browser/out/control-desktop.png` 与 `control-mobile.png`。测试命令见[浏览器说明](../apps/protected-browser/README.md#自动验收)。

## 剩余边界

浏览器仍有自己的会话服务与控制页面，尚未通过桌面统一宿主创建、授权、停止或恢复会话；本次仅对齐动作／批准格式与浏览器内部会话绑定。浏览器来源链明确标为未知；尚无此路径的脱敏持久审计和契约执行回执。HTTP 结果仍需在原业务页核实。

本次不证明系统隔离、普通浏览器覆盖、非 HTTP 出口、准确原生 App 身份或生产发布可用。没有运行模型付费长任务，也没有部署或发布。
