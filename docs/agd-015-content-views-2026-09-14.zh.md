## 本次交付

文件读取／搜索、浏览器读取和进程输出，均在实际读取时采集原始内容，分别记录原始、可见与检测视图的 SHA-256、字节数和完整性。原始捕获只在可信执行器与宿主之间传递，不回送模型或写入来源日志；两处只记录它的摘要和固定检测标记，正常可见正文仍返回模型。读取之后即使原路径被修改，来源摘要仍对应已经取得的字节，不重新打开路径来补造证明。

| 入口 | 原始采集范围 | 实际可见内容与限制 |
| --- | --- | --- |
| 文件读取 | 同一次读取的前 64 KiB 加 1 字节；额外字节用于确认截断 | 最多 64 KiB 正文；合法 UTF-8 字符边界不产生伪替换字符 |
| 文件搜索 | 同一次扫描的前 4 MiB 加 1 字节 | 最多 200 个命中行、64 KiB；明确区分完整扫描摘要与返回行摘要 |
| 进程输出 | stdout、stderr 各自最多 64 KiB 原字节，分别摘要 | 合并后的实际工具返回最多 64 KiB；坏编码和截断不等于完整检测 |
| 浏览器读取 | 同一次主文档 body 快照中的文本节点数组，包括普通隐藏节点和脚本文本；最多 10000 节点、128 KiB JSON 字节 | 保留 innerText 的可见正文和既有有限控件描述；不读取输入框、textarea、select 和 option 的已有值 |

浏览器原始视图保存节点边界，检测时才加入换行分隔，避免卡号末尾与下一节点的汉字直接拼成一个词。可见正文仍按真实渲染取值；正文最多 16000 个 UTF-16 单元，且转义后的 JSON 不超过 48 KiB。原始捕获字段在浏览器宿主返回模型前移除。文件执行器异常、回执截断或夹带额外输出时，也不把私有捕获包络作为错误正文回送。

## 检测与权限边界

检测复用现有文本规范化和隐私扫描，每个视图分别检查。正常 Unicode、组合字符、表情及引用攻击样例的研究文档仍可读取，不因出现关键词就阻断阅读。来源只记录三个布尔结果：已有结构／角色边界标记、文本异常、经校验确认的敏感实体；不保存匹配正文、实体值或任意页面自报说明。

这些标记不是通用语义注入判定，也不授予指令或批准权。可见和隐藏内容触发的后续动作仍通过同一权限及批准边界；实测两类注入后的授权外写入均未派发，实际文件均不存在。更换原始摘要会改变不可变动作摘要，旧批准无法复用。敏感度继续保守继承父来源，未知不会被普通正文清除。

视图状态明确区分 `complete`、`truncated`、`unsupported_encoding` 和 `detection_limited`。检测视图最多 64 个，超限保留部分状态。缺失或畸形捕获记为未知来源；来源持久化或校验失败时停止后续动作。完整状态仅指表中明确的采集范围，不表示全文件、全网页或内容安全。

## 范围与接续

本轮仅构建 CLI 并运行桌面测试，未打包或替换 Ver 1.0（010）App。新源码不借用 010 的原生验收；后续构建 M2 App 时需要递增版本，并在固定路径重新验收。
