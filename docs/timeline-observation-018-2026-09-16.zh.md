# 固定 App 018：活动时间与普通阅读误报

日期：2026-09-16。基线：`a7bc3bb285dd1f980daf1d516f19af3c6406ff66`。用户要求活动时间线显示时间，并分析普通操作为何提示风险。本次为桌面修复，不代表整个计划或发布通过。

## 原因

- 时间戳已经保存在审计记录的 `timestamp_ms` 中，旧前端没有显示。018 每条显示本地日期、时分秒和时区，并在语义时间元素中保留 UTC 值；无效或缺少时间显示“时间未知”，不补造当前时间。
- `OVL-007` 来自低对比度像素纹理，不能确认存在文字，更不能确认攻击。旧规则把单一纹理线索显示为告警；同一语义线索默认 30 秒后再次记录，内容变化也会形成新记录，所以用户看到了大量相似提示。
- `CRIT-005` 对整个窗口文字匹配 `Install`、`安装` 或 `Allow this app`，没有待执行安装动作的证据。用户截图是阅读 GitHub PR，其中普通正文就有“发布安装包”。旧描述“Agent is about to install software”超出了观察证据。实际旧审计也存在 `UiTreeDelta / CRIT-005 / Block`；由于原文未保存，不能反推每次命中的精确词句。

## 修正

引擎新增可信宿主调用的桌面观察入口，只接受 macOS／Windows 窗口与屏幕事件。本次接到 macOS 的真实观察路径。在这个上下文中，基础 `OVL-007` 和 `CRIT-005` 仅记录信息，不请求确认；前端分别解释低对比度误触发和“出现安装文字不等于正在安装”。普通受控执行入口不接受事件自报 `observed_only` 来降级，安装请求仍保持原批准要求。

调整发生在其它独立风险、受控规则包和企业策略合并之前，不能抹去明确注入、付款、身份冒充或更严格策略。历史审计保持当时的动作和用户选择，只增加时间及解释；因此旧记录仍可能显示原来的红色／橙色判决。其他规则的正常资料误报不因本次两项修正自动算作解决。
